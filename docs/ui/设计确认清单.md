# 设计确认清单

请在 G2 确认前逐项检查。

## App

- [ ] App 页面清单覆盖登录、任务、地块、点位、采集、拍照、草稿、上传、OCR、提交、退回、我的记录。
- [ ] App 字段覆盖 Plot_ID、Point_ID、Event_ID、Photo_ID、Manifest、metadata、OCR 和测量记录。
- [ ] App 按钮和操作覆盖保存草稿、上传、断点续传、OCR 校正、提交、退回修改。
- [ ] App 弱网/离线状态和上传队列策略可接受。
- [ ] App 退回复核不覆盖原始提交，使用修正版本。

## Web

- [ ] Web 菜单覆盖任务、地块、点位、采集事件、照片审核、OCR 校正、Provider 配置、统计、绩效、导出。
- [ ] Web 权限覆盖采集员、审核员、管理员、查看员。
- [ ] Web 列表、详情、审核、退回、导出状态完整。
- [ ] Web 配置项版本化策略可接受。

## 技术设计

- [ ] 数据库模型覆盖任务、地块、点位、事件、照片、测量、OCR、质检、导出、Provider、审计。
- [ ] API 契约覆盖 App 第一条闭环和 Web 管理操作。
- [ ] Provider 契约隔离高德、聚合天气、PaddleOCR、华为 OCR、人工录入。
- [ ] 图片、水印、上传、质检、导出和测试方案可接受。

## 门禁

- [ ] 确认 G2 后才允许创建业务代码目录和实现。
- [ ] 真实 Key、真机、真实样本缺失时，真实验收标记 `BLOCKED`。
