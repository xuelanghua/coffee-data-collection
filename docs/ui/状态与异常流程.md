# 状态与异常流程

## 采集事件状态

```text
草稿 -> 待上传 -> 上传中 -> 待OCR -> 待校正 -> 待提交 -> 已提交 -> 审核中 -> 通过
                                                        -> 退回 -> 退回修改中 -> 重新提交
```

规则：

- 草稿、待上传、上传中属于 App 本地和后端上传阶段。
- 已提交后原始采集包不可变。
- 退回修改生成修正版本，不覆盖原提交版本。

## 地块复核状态

```text
App 圈选中 -> 已生成正式地块/待复核 -> 后台已确认
                                  -> 后台已调整
                                  -> 退回重圈
                                  -> 作废
```

规则：

- App 现场圈选保存后立即生成正式 `Plot_ID`，可以继续创建点位和采集事件。
- 后台复核不阻塞现场采集。
- 后台调整边界时新增边界版本，不覆盖 App 原始圈选版本。
- 退回重圈时，原始地块和已提交采集包仍保留审计记录。

## 点位复核状态

```text
App 点选中 -> 已生成正式点位/待复核 -> 后台已确认
                                  -> 后台已调整
                                  -> 退回重选
                                  -> 停用
```

规则：

- App 现场点选保存后立即生成正式 `Point_ID`，可以继续创建采集事件。
- 后台复核检查点位是否落在地块边界内、定位精度是否满足要求。
- 已关联采集事件的点位不能物理删除。

## 照片状态

```text
本地新建 -> 预检通过/警告/阻断 -> 上传中 -> 已上传 -> 待审核 -> 通过
                                                        -> 退回补拍
                                                        -> 作废标记
```

阻断项：缺定位、缺水印、文件损坏、重复 Photo_ID、必拍分类缺失。  
警告项：轻微模糊、低光照、定位精度低、图片过大。

## OCR 状态

```text
未识别 -> 排队 -> 识别中 -> 成功 -> 待校正 -> 已校正
                         -> 失败 -> 重新识别/人工录入
                         -> 超时 -> 重试/人工录入
```

错误状态必须展示 Provider、错误码、错误摘要、是否可重试。

## 上传队列状态

```text
待上传 -> 分片中 -> 上传中 -> 校验中 -> 完成
                         -> 暂停
                         -> 失败可重试
                         -> 失败需人工处理
```

弱网策略：

- 网络断开时自动暂停并保留队列。
- 网络恢复后按任务优先级继续。
- 上传失败使用指数退避。
- 用户可选择仅 Wi-Fi 上传。

## 空状态

| 场景 | 文案 | 操作 |
|---|---|---|
| 无任务 | 暂无分配任务 | 同步任务 |
| 无地块 | 当前任务暂无地块，可现场圈选 | 新建地块 |
| 无点位 | 当前地块暂无点位，可现场点选 | 新建点位 |
| 无退回 | 暂无退回记录 | 返回任务 |
| Web 无数据 | 暂无符合条件的数据 | 清空筛选 |
| 无导出 | 暂无导出任务 | 新建导出 |

## 加载状态

- App 列表加载使用骨架屏或轻量 loading。
- App 关键提交显示步骤进度，不允许重复点击。
- Web 表格使用 Element Plus loading，导出和 OCR 使用任务进度。

## 错误状态

| 错误 | App 行为 | Web 行为 |
|---|---|---|
| 未登录/过期 | 返回登录并保留草稿 | 返回登录 |
| 无权限 | 展示无权限页 | 菜单不可见或按钮禁用 |
| 服务不可达 | 转入离线模式 | 顶部错误提示 |
| 幂等冲突 | 展示已有提交结果 | 展示冲突详情 |
| Provider 失败 | 排队重试或人工录入 | 查看调用日志和重试 |

## 退回复核流程

1. 审核员选择退回原因：缺照片、照片不清、OCR 错误、测量异常、地块/点位错误、B 级规则不通过。
2. 系统生成退回复核任务并通知采集员。
3. App 退回修改页按项展示需处理内容。
4. 采集员补拍、修正 OCR 或复测。
5. App 重新提交生成修正版本。
6. Web 显示原版本和修正版本差异。
7. 审核员复核通过或再次退回。

## 批量审核流程

1. 审核员在采集事件列表或数据包审核页筛选待审核数据。
2. 勾选多条记录。
3. 系统预检查阻断项、权限和状态一致性。
4. 批量通过：无阻断项时生成逐条审核通过记录。
5. 批量退回：审核员选择统一退回原因和退回项，系统为每条记录生成退回任务。
6. 批量操作结果展示成功、失败、跳过清单。
7. 每条记录独立写入审计日志，不能只保存一条批量摘要。
