# Web 管理端页面设计说明

## 菜单结构

| 一级菜单 | 二级页面 | 主要角色 |
|---|---|---|
| 咖啡采集 | 任务管理、地块管理、点位管理、采集事件、照片资产 | 管理员、审核员、查看员 |
| 质检审核 | 数据包审核、照片审核、退回复核、B 级规则检查 | 审核员、管理员 |
| OCR 与 Provider | OCR 任务、OCR 校正、Provider 配置、调用日志 | 审核员、管理员 |
| 统计导出 | 采集进度、质量统计、绩效统计、导出任务 | 管理员、查看员 |
| 系统配置 | 采集字典、照片分类、设备模板、质检规则、角色权限初始化 | 管理员 |

## W01 任务管理

字段：任务编号、名称、区域、计划日期、负责人、采集员、状态、地块数、点位数、完成率。  
按钮：新增、编辑、分配采集员、启停、生成编号、导入地块点位、导出。  
权限：管理员全量；审核员只读；查看员只读。  
状态：草稿、已发布、进行中、暂停、已完成、已关闭。

## W02 地块管理

字段：Plot_ID、地块名称、行政区、边界 GeoJSON、面积、面积复核状态、点位数。  
按钮：新增、导入、编辑边界、面积复核、查看地图、作废。  
异常：边界缺失、面积超差、坐标系不一致。

## W03 点位管理

字段：Point_ID、Plot_ID、经纬度、海拔、编号来源、点位状态、最近采集事件。  
按钮：新增、批量导入、地图选点、启停、查看事件。  
规则：已有关联事件的点位不能物理删除，只能停用。

## W04 采集事件列表

字段：Event_ID、任务、Plot_ID、Point_ID、采集员、状态、照片数、OCR 状态、质检状态、提交时间。  
按钮：详情、审核、退回、标记异常、导出事件包。  
筛选：任务、地块、点位、采集员、状态、日期、退回原因。

## W05 采集事件详情

布局：基础信息、定位轨迹、照片、测量记录、OCR 结果、质检记录、审计日志。  
按钮：通过、退回、要求复测、导出、查看 Manifest。  
权限：审核员可审核；查看员只读；管理员可处理异常。

## W06 照片资产

字段：Photo_ID、Event_ID、分类、原图 Hash、水印状态、metadata、预检结果、审核状态。  
按钮：预览原图、查看 metadata、审核通过、退回补拍、标记作废、下载受控副本。  
规则：原图不可变；标记作废不删除文件。

## W07 数据包审核

字段：Event_ID、完整性、Manifest、必拍分类、测量完整性、OCR 完整性、B 级规则。  
按钮：批量通过、批量退回、生成审核报告。  
状态：待审核、审核中、通过、退回、复核中。

## W08 OCR 任务

字段：任务号、Provider、Photo_ID、状态、耗时、置信度、错误码、调用时间。  
按钮：重新识别、切换 Provider、查看原始响应、查看调用日志。  
状态：排队、识别中、成功、失败、超时、人工录入。

## W09 OCR 校正

字段：识别字段、原始值、置信度、人工值、修正原因、修正人、版本。  
按钮：保存修正、恢复上一版本、提交复核、查看原始响应。  
规则：修正新增版本，不覆盖原始 OCR。

## W10 Provider 配置

字段：Provider 类型、名称、启用状态、优先级、超时、限流、配置状态、脱敏 Key。  
按钮：新增、编辑、启停、连接测试、查看调用日志。  
权限：仅管理员可编辑；审核员只读调用日志。

## W11 质检规则和 B 级规则

字段：规则名称、适用任务、阈值、阻断级别、启用状态、版本。  
按钮：新增规则、编辑、复制版本、启停、模拟检查。  
规则：已使用版本不可修改，只能复制新版本。

## W12 统计报表

视图：采集进度、照片质量、OCR 命中率、退回原因、地块覆盖、B 级数量。  
按钮：筛选、刷新、导出图表、保存视图。  
权限：管理员全量；查看员只读授权范围。

## W13 绩效统计

字段：采集员、任务数、事件数、通过率、退回率、补拍次数、平均提交时长。  
按钮：筛选、导出、查看明细。  
规则：绩效只用于过程统计，不直接覆盖业务验收。

## W14 导出任务

字段：任务编号、导出类型、筛选条件、状态、进度、文件大小、过期时间。  
按钮：新建导出、取消、下载、重试、删除过期文件。  
状态：排队、处理中、完成、失败、已过期。

## W15 系统配置

页面：采集字典、照片分类、设备模板、字段配置、角色权限初始化。  
按钮：新增、编辑、导入、导出、启停、版本复制。  
规则：影响历史数据解释的配置必须版本化。
