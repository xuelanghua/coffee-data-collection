# 字段与按钮清单

## 核心标识字段

| 字段 | 说明 | 生成方式 | 可编辑性 |
|---|---|---|---|
| Plot_ID | 地块主键 | App 现场圈选后生成，或 Web 创建/导入 | 创建后不可改 |
| Point_ID | 采样点主键 | App 现场点选后生成，或 Web 创建/导入 | 创建后不可改 |
| Event_ID | 采集事件主键 | App 本地幂等键 + 后端确认 | 创建后不可改 |
| Photo_ID | 照片资产主键 | App 拍照时生成 + 后端确认 | 创建后不可改 |
| Manifest_ID | 数据包清单编号 | App 提交前生成 | 新版本新增 |
| Idempotency_Key | 幂等键 | App 生成 | 不可改 |

## 采集字段

| 字段 | App | Web | 说明 |
|---|---|---|---|
| task_id | 只读 | 可配置 | 任务 |
| plot_id | 现场圈选/选择 | 查看/复核/配置 | 地块 |
| point_id | 现场点选/选择 | 查看/复核/配置 | 点位 |
| collected_at | 自动 | 只读 | 采集时间 |
| collector_id | 自动 | 可筛选 | 采集员 |
| location | 自动/手动修正 | 查看/复核 | 经纬度、精度、坐标系 |
| weather_snapshot | 自动/手动 | 查看 | 天气 Provider 快照 |
| device_no | 输入/选择 | 配置 | 测量设备 |
| notes | 输入 | 查看 | 备注 |

## 照片字段

| 字段 | 说明 |
|---|---|
| category | 地块环境、植株、果实、设备采集屏幕、样品袋/标签、异常补充 |
| original_file | 不可变原图 |
| watermarked_file | 带水印展示副本 |
| sha256 | 文件 Hash |
| metadata | EXIF、设备、定位、时间、App 版本 |
| precheck_status | 通过、警告、阻断 |
| review_status | 待审、通过、退回、作废 |

## OCR 字段

| 字段 | 说明 |
|---|---|
| provider | paddleocr、huawei_ocr、manual |
| raw_response | 原始响应，只增不改 |
| structured_result | 结构化识别结果 |
| confidence | 字段级或整体置信度 |
| corrected_value | 人工修正值 |
| correction_reason | 修正原因 |
| call_log_id | Provider 调用日志 |

| rainfall | 雨量 | mm | OCR 回填，可手动校准 |
| soil_moisture | 土壤湿度 | % | OCR 回填，可手动校准 |
| soil_temperature | 土壤温度 | 摄氏度 | OCR 回填，可手动校准 |

## App 关键按钮

| 按钮 | 页面 | 规则 |
|---|---|---|
| 登录 | 登录页 | 在线校验 |
| 同步任务 | 任务首页 | 拉取任务和离线包 |
| 开始采集 | 任务详情 | 进入地块圈选和点位创建 |
| 圈选地块 | 地块地图 | 生成正式 Plot_ID，后台事后复核 |
| 保存点位 | 点位创建 | 生成正式 Point_ID，后台事后复核 |
| 创建事件 | 点位详情 | 生成 Event_ID |
| 拍照 | 分类拍照 | 生成 Photo_ID |
| 保存草稿 | 表单页 | 离线可用 |
| 上传 | 上传队列 | 分片、断点续传 |
| OCR 识别 | 设备采集数据页 | 识别设备采集屏幕照片并回填 10 个设备字段 |
| 保存校准 | 设备采集数据页 | 保存输入框中的人工校准值，最终提交时生成修正版本 |
| 提交 | 提交确认 | 幂等提交 |
| 重新提交 | 退回修改 | 生成修正版本 |
