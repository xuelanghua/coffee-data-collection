# App 页面设计说明

## 页面清单

| 编号 | 页面 | 角色 | 目的 |
|---|---|---|---|
| A01 | 登录页 | 全部 | 手机号 + 密码登录 |
| A02 | 任务首页 | 采集员、管理员 | 查看今日/全部采集任务 |
| A03 | 任务详情 | 采集员、管理员 | 查看任务范围、进度、说明和离线包状态 |
| A04 | 地块列表 | 采集员 | 按任务选择地块 |
| A05 | 地块地图 | 采集员 | 查看边界、点位、当前位置和面积复核结果 |
| A06 | 点位详情 | 采集员 | 查看 Point_ID、状态、坐标和历史 |
| A07 | 创建采集事件 | 采集员 | 生成 Event_ID，填写基础环境和设备信息 |
| A08 | 分类拍照 | 采集员 | 按分类拍摄原图并写入水印与 metadata |
| A09 | 照片预检 | 采集员 | 检查模糊、缺分类、缺定位、重复照片 |
| A10 | 设备测量录入 | 采集员 | 录入设备读数、单位、异常复测 |
| A11 | OCR 识别结果 | 采集员 | 查看识别状态、原始结果和置信度 |
| A12 | OCR 人工校正 | 采集员 | 将 OCR 结果修正到字段值 |
| A13 | 本地草稿 | 采集员 | 管理离线草稿和未提交事件 |
| A14 | 上传队列 | 采集员 | 查看分片、断点续传和失败重试 |
| A15 | 提交确认 | 采集员 | 检查 Manifest、Hash、必填项和质检摘要 |
| A16 | 退回修改 | 采集员 | 查看退回原因并补拍、校正、复测后重提 |
| A17 | 我的记录 | 采集员 | 查看本人采集历史 |
| A18 | 记录详情 | 采集员、管理员 | 查看采集包、照片、OCR、质检、审计 |
| A19 | 消息通知 | 采集员、审核员 | 任务变更、退回、审核结果 |
| A20 | 我的/设置 | 全部 | 账号、离线存储、清理缓存、诊断上传 |

## 关键流程

登录 -> 任务首页 -> 任务详情 -> 地块列表/地图 -> 点位详情 -> 创建采集事件 -> 分类拍照 -> 设备测量 -> 照片预检 -> 保存草稿 -> 上传队列 -> OCR 识别 -> 人工校正 -> 提交确认 -> Web 审核。

## A01 登录页

字段：手机号、密码、记住账号、环境标识。  
按钮：登录、清空、查看本机诊断。  
状态：未登录、登录中、登录失败、账号无权限、离线不可登录。  
错误：手机号格式错误、密码错误、账号禁用、服务器不可达。  
权限：全部用户可见。

## A02 任务首页

字段：任务编号、任务名称、采集区域、计划日期、进度、待退回数、离线包状态。  
按钮：同步任务、进入任务、查看退回、离线包下载。  
状态：空任务、加载中、同步失败、离线可用、离线包过期。  
权限：采集员只看分配任务，管理员可看全部。

## A03 任务详情

字段：任务基本信息、采集规范、P0 必填要求、地块数、点位数、已采/待采、退回数。  
按钮：开始采集、下载离线包、查看地图、刷新。  
状态：未开始、进行中、已完成、暂停、已关闭。  
错误：任务已关闭时禁止新增事件。

## A04/A05 地块列表和地块地图

字段：Plot_ID、地块名称、边界面积、面积复核状态、点位数量、采集完成率。  
按钮：筛选、进入地块、地图定位、手动选点、面积复核。  
状态：定位中、定位失败、边界缺失、坐标系异常、弱网地图降级。  
离线：离线显示缓存瓦片/简化边界，允许手动选点并记录待复核。

## A06 点位详情

字段：Point_ID、Plot_ID、经纬度、海拔、点位状态、最近事件、历史退回。  
按钮：创建采集事件、查看历史、导航、手动修正点位。  
规则：同一任务下未完成退回复核时提示优先处理退回。

## A07 创建采集事件

字段：Event_ID、采集时间、采集员、天气快照、定位快照、设备编号、备注。  
按钮：保存草稿、继续拍照、取消。  
规则：先编号后采集；Event_ID 在本地生成幂等键并由后端确认。

## A08 分类拍照

分类：地块环境、植株、果实、设备读数、样品袋/标签、异常补充。  
字段：Photo_ID、分类、拍摄时间、定位、设备信息、原图 Hash、水印状态。  
按钮：拍照、从相机重拍、预览、删除本地未上传照片。  
规则：上传后原图不可删除，只能追加作废标记和补拍记录。

## A09 照片预检

检查项：必拍分类、图片清晰度、定位、时间、水印、重复、大小、格式。  
按钮：重新检查、补拍、进入上传。  
状态：通过、警告、阻断。阻断项必须处理后才能提交。

## A10 设备测量录入

字段：设备类型、设备编号、测量项目、读数、单位、测量时间、异常标记、复测原因。  
按钮：添加读数、标记异常、复测、保存。  
规则：异常读数不覆盖原记录，复测新增记录并关联原记录。

## A11/A12 OCR 识别与人工校正

字段：Provider、识别状态、原始响应、结构化字段、置信度、人工修正值、修正原因。  
按钮：发起识别、重新识别、人工录入、保存校正、查看原始响应。  
规则：OCR 结果自动填入输入框；人工校正保留版本和审计。

## A13/A14 草稿与上传队列

字段：草稿数、待上传照片、失败分片、Manifest Hash、重试次数、网络状态。  
按钮：继续编辑、上传、暂停、重试、诊断。  
弱网：自动排队、断点续传、指数退避；用户可手动暂停。

## A15 提交确认

字段：必填完整性、照片分类、OCR 校正、测量记录、Manifest、Hash、预检结论。  
按钮：提交、返回修改、保存草稿。  
规则：提交使用幂等键，重复提交返回同一结果。

## A16 退回修改

字段：退回原因、审核员、退回时间、需处理项、原提交版本、新修正版本。  
按钮：按项修改、补拍、重新提交、联系审核员。  
规则：退回复核不改原提交包，生成修正版本。

## A17-A20 我的记录、详情、通知、设置

字段：记录编号、状态、任务、地块、点位、提交时间、审核结果、同步诊断。  
按钮：查看详情、筛选、清理已提交缓存、导出诊断包。  
设置：离线容量、仅 Wi-Fi 上传、日志脱敏、版本号、退出登录。
