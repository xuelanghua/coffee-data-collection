# App 页面设计说明

## 页面清单

| 编号 | 页面 | 角色 | 目的 |
|---|---|---|---|
| A01 | 登录页 | 全部 | 手机号 + 密码登录 |
| A02 | 任务首页 | 采集员、管理员 | 查看今日/全部采集任务 |
| A03 | 任务详情 | 采集员、管理员 | 查看任务范围、进度、说明和离线包状态 |
| A04 | 地块列表 | 采集员 | 查看已圈选地块，或进入地图新建地块 |
| A05 | 地块圈选地图 | 采集员 | 现场圈选种植地块边界并自动计算面积 |
| A06 | 点位创建/详情 | 采集员 | 在现场地块内点选采集点并查看 Point_ID |
| A07 | 创建采集事件 | 采集员 | 生成 Event_ID，填写基础环境和设备信息 |
| A08 | 分类拍照 | 采集员 | 按分类拍摄原图并写入水印与 metadata |
| A09 | 照片预检 | 采集员 | 检查模糊、缺分类、缺定位、重复照片 |
| A10 | 设备采集数据 | 采集员 | 通过 OCR 回填并人工校准风速、风向、空气温湿度、气压、雨量和土壤指标 |
| A11 | OCR 识别结果 | 采集员 | 查看识别状态、原始结果和置信度 |
| A12 | OCR 人工校正 | 采集员 | 将 OCR 结果修正到字段值 |
| A13 | 本地草稿 | 采集员 | 管理离线草稿和未提交事件 |
| A14 | 上传队列 | 采集员 | 查看分片、断点续传和失败重试 |
| A15 | 提交确认 | 采集员 | 检查 Manifest、Hash、必填项和质检摘要 |
| A16 | 退回修改 | 采集员 | 查看退回原因并补拍、校正、复测后重提 |
| A17 | 我的记录 | 采集员 | 查看本人采集历史 |
| A18 | 记录详情 | 采集员、管理员 | 查看采集包、照片、OCR、质检、审计 |
| A19 | 消息通知 | 采集员、审核员 | 任务变更、退回、审核结果 |
| A20 | 我的/设置 | 全部 | 账号、离线存储、清理缓存、诊断上传 |

## 关键流程

登录 -> 任务首页 -> 任务详情 -> 地块圈选地图 -> 自动计算面积 -> 创建正式地块 -> 地块内点选采集点 -> 创建正式点位 -> 创建采集事件 -> 分类拍照设备屏幕 -> 照片上传 -> OCR 实时识别设备采集数据 -> 自动填入对应输入框 -> 人工校准 -> 照片预检 -> 保存草稿 -> 最终提交 -> Web 审核/复核。

## A01 登录页

字段：手机号、密码、记住账号、环境标识。  
按钮：登录、清空、查看本机诊断。  
状态：未登录、登录中、登录失败、账号无权限、离线不可登录。  
错误：手机号格式错误、密码错误、账号禁用、服务器不可达。  
权限：全部用户可见。

## A02 任务首页

字段：任务编号、任务名称、采集区域、计划日期、进度、待退回数、离线包状态。  
按钮：同步任务、进入任务、查看退回、离线包下载。  
状态：空任务、加载中、同步失败、离线可用、离线包过期。  
权限：采集员只看分配任务，管理员可看全部。

## A03 任务详情

字段：任务基本信息、采集规范、P0 必填要求、地块数、点位数、已采/待采、退回数。  
按钮：开始采集、下载离线包、查看地图、刷新。  
状态：未开始、进行中、已完成、暂停、已关闭。  
错误：任务已关闭时禁止新增事件。

## A04/A05 地块列表和地块圈选地图

字段：Plot_ID、地块名称、边界 Polygon、自动计算面积、面积计算方法、坐标系、复核状态、点位数量、采集完成率。  
按钮：新建地块、开始圈选、撤销上一点、闭合边界、重新圈选、保存地块、进入点位。  
状态：定位中、定位失败、圈选中、面积计算中、保存中、待后台复核、坐标系异常、弱网地图降级。  
规则：App 现场圈选保存后生成正式 `Plot_ID`，可立即进入点位创建和采集；后台复核不阻塞现场采集。  
离线：允许本地保存圈选地块草稿；联网后同步生成正式 `Plot_ID`。如无法生成正式编号，App 使用本地临时编号并在同步后替换为后端确认编号。

## A06 点位创建/详情

字段：Point_ID、Plot_ID、经纬度、海拔、坐标系、定位精度、点位复核状态、最近事件、历史退回。  
按钮：地图点选、使用当前位置、重新定位、保存点位、创建采集事件、查看历史。  
规则：App 现场点选保存后生成正式 `Point_ID`，可立即创建采集事件；后台复核点位是否落在地块边界内和是否符合任务规则。

## A07 创建采集事件

字段：Event_ID、采集时间、采集员、天气快照、定位快照、设备编号、备注。  
按钮：保存草稿、继续拍照、取消。  
规则：先编号后采集；Event_ID 在本地生成幂等键并由后端确认。

## A08 分类拍照

分类：地块环境、植株、果实、设备采集屏幕、样品袋/标签、异常补充。  
字段：Photo_ID、分类、拍摄时间、定位、设备信息、原图 Hash、水印状态。  
按钮：拍照、从相机重拍、预览、删除本地未上传照片。  
规则：上传后原图不可删除，只能追加作废标记和补拍记录。

## A09 照片预检

检查项：必拍分类、图片清晰度、定位、时间、水印、重复、大小、格式。  
按钮：重新检查、补拍、进入上传。  
状态：通过、警告、阻断。阻断项必须处理后才能提交。

## A10 设备采集数据

字段：设备编号、采集时间、风速、风向、空气温度、空气湿度、大气压力、雨量、土壤湿度、土壤温度、土壤盐分、土壤 PH 值、异常标记、复测原因。  
按钮：OCR 识别、重新识别、人工录入、标记异常、复测、保存草稿。  
规则：OCR 识别出的设备采集数据自动填入对应输入框；采集员可直接在输入框中手动校准。异常读数不覆盖原记录，复测新增记录并关联原记录。

## A11/A12 OCR 识别与人工校正

字段：Provider、识别状态、原始响应、风速、风向、空气温度、空气湿度、大气压力、雨量、土壤湿度、土壤温度、土壤盐分、土壤 PH 值、字段置信度、人工修正值、修正原因。  
按钮：发起识别、重新识别、人工录入、查看原始响应。  
规则：OCR 识别的数据就是设备采集数据。识别结果自动填入当前页面对应输入框；用户在输入框中手动校准后先保存在本地表单状态，最终随提交接口一次性落库。后端保存最终字段值，并为发生变化的 OCR 字段生成修正版本和审计记录。

## A13/A14 草稿与上传队列

字段：草稿数、待上传照片、失败分片、Manifest Hash、重试次数、网络状态。  
按钮：继续编辑、上传、暂停、重试、诊断。  
弱网：自动排队、断点续传、指数退避；用户可手动暂停。

## A15 提交确认

字段：必填完整性、照片分类、OCR 校正、测量记录、Manifest、Hash、预检结论。  
按钮：提交、返回修改、保存草稿。  
规则：提交使用一个最终提交接口和幂等键。图片上传与 OCR 识别在提交前完成；最终提交包含 Manifest、最终字段值、照片引用、测量记录、OCR 纠正摘要和 Hash。重复提交返回同一结果。

## A16 退回修改

字段：退回原因、审核员、退回时间、需处理项、原提交版本、新修正版本。  
按钮：按项修改、补拍、重新提交、联系审核员。  
规则：退回复核不改原提交包，生成修正版本。

## A17-A20 我的记录、详情、通知、设置

字段：记录编号、状态、任务、地块、点位、提交时间、审核结果、同步诊断。  
按钮：查看详情、筛选、清理已提交缓存、导出诊断包。  
设置：离线容量、仅 Wi-Fi 上传、日志脱敏、版本号、退出登录。
