# 普洱咖啡数据采集系统本地运行使用说明

## 1. 适用范围

本文档基于当前仓库中的实际开发结果整理，适用于在本机启动以下服务：

- Django 后端
- Vue Web 前端
- PaddleOCR 契约服务
- 本机 MySQL 8.0 联调环境

当前已经验证通过的访问地址：

- Web：`http://127.0.0.1:8080/`
- API Swagger：`http://127.0.0.1:8000/swagger/`
- PaddleOCR 健康检查：`http://127.0.0.1:8001/health`

说明：

- OBS / 华为 OCR 当前不作为自动本地启动前置条件。
- Docker Compose 方案已调整为 MySQL 8.0，但镜像拉取在当前环境里曾出现不稳定，建议优先使用“本机 MySQL 8.0 直连方案”。

## 2. 环境要求

建议本机准备：

- macOS
- Python 3.9
- Node.js 与 npm
- MySQL 8.0
- 可选：Docker Desktop

当前项目开发中实际验证过的本机 MySQL 连接方式示例：

```bash
mysql -h 127.0.0.1 -P 3306 -u root -p
```

## 3. 代码目录说明

- `dvadmin-backend/`：Django 后端
- `dvadmin-ui/`：Vue 2 Web 管理端
- `services/paddleocr/`：PaddleOCR 契约服务
- `.env.example`：根目录环境变量示例
- `dvadmin-backend/conf/env.example.py`：后端本地配置示例
- `scripts/verify-local-mysql8.sh`：本机 MySQL 8.0 一键验证脚本

## 4. 首次配置

### 4.1 根目录环境变量

在项目根目录执行：

```bash
cp .env.example .env
```

至少需要检查这些变量：

```bash
DJANGO_SECRET_KEY=
MYSQL_DATABASE=coffee_collection
MYSQL_USER=coffee_app
MYSQL_PASSWORD=
MYSQL_ROOT_PASSWORD=
CONFIG_ENCRYPTION_KEY=
CORS_ALLOWED_ORIGINS=http://127.0.0.1:8080,http://localhost:8080
```

说明：

- `.env` 只用于本机，不能提交到 Git。
- `CORS_ALLOWED_ORIGINS` 已加入本地前端地址，保证登录验证码和接口请求可用。

### 4.2 后端本地配置

执行：

```bash
cd dvadmin-backend
cp conf/env.example.py conf/env.py
```

说明：

- `dvadmin-backend/conf/env.py` 是本机文件，不能提交到 Git。
- 默认读取根目录 `.env` 中的大部分配置。

### 4.3 Python 虚拟环境

执行：

```bash
cd dvadmin-backend
python3 -m venv .venv
.venv/bin/pip install -r requirements-mysql.txt
```

说明：

- 当前项目需要 `requirements-mysql.txt`，因为本地联调走 MySQL 8.0。
- 如果你本机安装的是 MySQL 官方客户端，`mysqlclient` 编译可能需要 MySQL 头文件和库路径。

### 4.4 前端依赖

执行：

```bash
cd dvadmin-ui
npm install
```

## 5. 本机 MySQL 8.0 直连方案

这是当前最推荐的本地运行方式。

### 5.1 准备数据库

确保本机已有数据库和用户，例如：

- 数据库：`coffee_collection`
- 用户：`coffee_app`

如果你使用 root 初始化，可以手动创建：

```sql
CREATE DATABASE coffee_collection DEFAULT CHARACTER SET utf8mb4;
CREATE USER 'coffee_app'@'%' IDENTIFIED BY '你的密码';
GRANT ALL PRIVILEGES ON coffee_collection.* TO 'coffee_app'@'%';
GRANT ALL PRIVILEGES ON test_coffee_collection.* TO 'coffee_app'@'%';
FLUSH PRIVILEGES;
```

### 5.2 一键验证数据库链路

在项目根目录执行：

```bash
./scripts/verify-local-mysql8.sh
```

该脚本会验证：

- MySQL 版本是否为 8.0
- Django `verify_mysql8`
- 数据库迁移
- 初始化菜单与数据
- `manage.py check`
- MySQL 相关测试

## 6. 启动服务

建议开 3 个终端窗口，分别启动后端、OCR、前端。

### 6.1 启动 Django 后端

```bash
cd dvadmin-backend
set -a
. ../.env
set +a
export DATABASE_HOST=127.0.0.1
export DATABASE_PORT=3306
export REDIS_ENABLE=false
export API_LOG_ENABLE=false
export DYLD_LIBRARY_PATH=/usr/local/mysql/lib:$DYLD_LIBRARY_PATH
.venv/bin/python manage.py runserver 127.0.0.1:8000 --noreload
```

### 6.2 启动 PaddleOCR 契约服务

```bash
cd services/paddleocr
PYTHONPATH=. ../../dvadmin-backend/.venv/bin/python service.py
```

### 6.3 启动 Web 前端

```bash
cd dvadmin-ui
npm run dev -- --host 127.0.0.1 --port 8080
```

启动成功后访问：

- Web 登录页：`http://127.0.0.1:8080/login?redirect=%2Findex`
- Swagger：`http://127.0.0.1:8000/swagger/`

## 10. 常见问题

### 10.1 登录页验证码不显示

排查顺序：

1. 打开 `http://127.0.0.1:8000/admin/captcha/refresh/` 看是否返回 JSON。
2. 检查 `http://127.0.0.1:8000/admin/captcha/image/<key>/` 是否返回图片。
3. 检查后端是否返回 `Access-Control-Allow-Origin: http://127.0.0.1:8080`。
4. 确认前端确实运行在 `127.0.0.1:8080`。

### 10.2 MySQL 测试库权限不足

如果测试时报 `test_coffee_collection` 权限问题，给业务用户补权限：

```sql
GRANT ALL PRIVILEGES ON test_coffee_collection.* TO 'coffee_app'@'%';
FLUSH PRIVILEGES;
```

### 10.3 Redis 没有密码

当前项目已经支持本地 Redis 无密码模式。若仅做本机联调，也可以直接设置：

```bash
REDIS_PASSWORD=
REDIS_ENABLE=false
```

如果你不需要 Celery / Redis，本机启动后端时可以直接禁用 Redis。

### 10.4 OBS / 华为 OCR 未配置

这不会阻塞当前 Web、API、PaddleOCR 契约服务的启动。

## 11. 停止服务

如果你是前台启动，分别在对应终端按：

```bash

```

如果你需要按端口查进程：

```bash
lsof -nP -iTCP:8000 -sTCP:LISTEN
lsof -nP -iTCP:8001 -sTCP:LISTEN
lsof -nP -iTCP:8080 -sTCP:LISTEN
```
