# 采集、图片、上传、质检和导出方案

## 图片和水印

原图策略：

- App 拍照生成 `Photo_ID`、本地文件 Hash、metadata。
- 原图作为不可变资产上传，后续不得覆盖。
- 水印图是展示副本，水印内容包括任务、Plot_ID、Point_ID、Event_ID、Photo_ID、时间、经纬度、采集员。
- metadata 保存设备型号、App 版本、定位精度、坐标系、拍摄时间、图片宽高、文件大小。

预检规则：

- 必拍分类完整性。
- 文件可读、格式允许、大小限制。
- Hash 去重。
- 定位和时间存在。
- 水印生成成功。
- 模糊、低光照作为警告；文件损坏、缺定位、缺必拍分类作为阻断。

## 上传和 Manifest

上传流程：

1. App 初始化照片上传，后端返回上传会话。
2. App 按分片上传，记录分片 Hash。
3. 后端校验分片完整性。
4. App 调用 complete，后端合并并校验原图 Hash。
5. App 提交 Manifest，绑定事件、照片、测量、OCR 校正摘要。
6. 后端使用幂等键处理重复提交。

Manifest 内容：

- 事件主键和幂等键。
- 地块、点位、采集员和时间。
- 照片列表、分类、Hash、metadata 摘要。
- 测量记录。
- OCR 结果和人工修正摘要。
- App 版本、离线包版本、Manifest Hash。

弱网策略：

- 本地草稿和上传队列分离。
- 断网自动暂停，恢复后继续。
- 分片上传支持重试。
- 重复 complete 和 submit 返回同一结果。

## OCR

OCR 调用：

- 设备读数类照片默认进入 OCR 队列。
- PaddleOCR 作为本地服务 Provider。
- 华为 OCR 作为外部 Provider，真实配置缺失时标记 `BLOCKED`。
- 人工录入作为兜底 Provider。

保存规则：

- 原始响应只增不改。
- 结构化结果可重新生成版本。
- 人工校正保存字段级修正值、原因、人员、时间和版本。

## 质检和退回

质检维度：

- 数据完整性：任务、地块、点位、事件、照片、测量。
- 图片质量：分类、清晰度、水印、metadata、原图 Hash。
- OCR 质量：置信度、人工校正、必填字段。
- 规则质量：B 级数量规则、异常复测、面积复核。

退回项：

- 缺必拍照片。
- 照片不清或分类错误。
- OCR 未校正或置信度低。
- 测量异常未复测。
- 点位或地块选择错误。
- B 级规则不通过。

退回后 App 生成修正版本。Web 审核页必须显示原版本、修正版本和差异。

## 导出

导出类型：

- 采集事件明细。
- 照片资产清单。
- OCR 结果和修正记录。
- 质检审核记录。
- 统计报表。
- 数据集包：Manifest、结构化数据、受控图片副本、审计摘要。

导出规则：

- 导出任务异步执行。
- 导出文件有权限、过期时间和下载审计。
- 大导出限流，避免阻塞 API。
- 导出包中的原图按权限控制；默认使用受控副本。

## 验收证据

- 本地自动测试：Manifest、Hash、幂等、状态流转、质检规则。
- Mock 证据：Provider 契约、OCR Mock、地图/天气 Mock。
- 真实证据：真实 Key、真机、真实样本、准生产环境，缺失即 `BLOCKED`。
